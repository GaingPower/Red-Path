# Red-Path

**In order to use correctly our simulator some steps must be folowed:**

_**Please** read first all the steps and then execute them._

    1- **Create** a folder in witch all the repository  must go to.
  
    2- **Download** the file from the repository.
  
    3- **Download** Visual Studio Code.
  
    4- **Open** the folder in VS Code.
  
    5- **Click** on the sphere button to open a internal browser wher the simulator will open.
  
  *You may now play!*
